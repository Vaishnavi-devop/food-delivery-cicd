# Food Delivery CI/CD

End-to-End CI/CD Deployment of a Java Food Delivery Application.

## Technologies

- Java 17
- Spring Boot
- Maven
- MySQL
- Git
- GitHub
- Jenkins
- Docker
- Docker Hub
- Kubernetes
- Amazon EKS
- Amazon RDS
- Amazon EC2

## Application APIs

### Health

GET /api/health

### Restaurants

GET /api/restaurants

### Menu

GET /api/menu

### Create Order

POST /api/orders

### Get Orders

GET /api/orders

## CI/CD Architecture

Developer
↓
GitHub
↓
Jenkins
↓
Maven
↓
Docker
↓
Docker Hub
↓
Amazon EKS
↓

## Project Purpose

This project demonstrates an end-to-end DevOps CI/CD implementation using AWS, Jenkins, Docker, Kubernetes and Spring Boot.
